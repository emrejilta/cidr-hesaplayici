# IPv4 CIDR Laboratuvarı

Tarayıcıda çalışan IPv4 CIDR hesaplayıcı

## Özellikler
- IPv4 adresi ve /0–/32 CIDR ön eki doğrulama
- Ağ adresi, alt ağ maskesi, wildcard mask, yayın adresi, adres/host sayısı
- İlk ve son kullanılabilir adres; /31 (RFC 3021) ve /32 özel durumları
- İkili gösterim ve ağ/host bitlerini renklendirme
- Eşit boyutlu alt ağların listelenmesi (ilk 64 satır)
- Mobil uyumlu, API ve veritabanı gerektirmeyen arayüz
